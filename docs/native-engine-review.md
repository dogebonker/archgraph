Validation also caught and fixed two native defects: projecting a source `__all__` onto every wildcard provider in Django, and losing the `type` token when the pinned TypeScript grammar reports `export type *` as an error node. Focused regressions cover explicit-versus-wildcard bindings, genuinely ambiguous providers, and internal/external type-star reexports. The latter still records the grammar syntax limitation; recovery only recognizes that exact AST error shape.

The default remains `reference`. Class erasure, wildcard narrowing, unresolved dependency metadata and bundler-specific forwarding remain material differences. The benchmark covers the existing 20 TypeScript/JavaScript and Python pins; Go, Rust, Java and Elixir have focused collector/CLI tests, not a comparable real-repository agreement study. No application build, TypeScript emission or Turbopack execution was used to validate these examples.
